# Changelog

## 0.1.0 — 2026-10-16

Initial release with a typed React API built on MUI.

- Search, sorting, pagination, built-in/custom filters, removable chips, and staged filter confirmation.
- Selection, bulk actions, conditional expansion, nested rows, grouped/collapsible columns, and sticky columns.
- Column visibility, ordering, and resizing with keyboard controls.
- CSV export, text-only printing, controlled server state, saved views, and localization.
- Replaceable components and renderers; a playground with four themes and 46 customization examples.

Requires React 19.3.1+ and MUI 9.5+ within their respective major versions. ES modules only. This is an independent API, not a drop-in mui-datatables replacement.

Chromium and Firefox desktop/mobile layouts were reviewed. Safari/WebKit, physical devices, manual screen-reader use, and native print dialogs remain unverified.
